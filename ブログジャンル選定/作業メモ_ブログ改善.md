## 決めた方針（CLAUDE.md にも記載）

- 一人称は「私」で統一する（過去記事の「僕」は改稿時に直す）
- テーマ外の記事（AGA・スキンケア・防災・県議会など）も当面は残す。まずは投稿を続けることを優先し、振り分けは後で行う
- カテゴリは「心・からだ・暮らし」から少し増やす方向で検討中
- 改稿はテーマに近い記事から1本ずつ。改稿前の本文は backup/ に保存してから上書きする
- 改稿時は関連記事への内部リンクを入れる
- 実体験は作らない。足りない場面は本人に聞いてから書く

## 全記事を見て分かった課題

### ブログ全体
1. **ジャンルが散らばっている**：恋愛のど真ん中の記事は5本ほど。テーマ外の記事が多い
2. **カテゴリが3つだけ**：恋愛記事が「暮らし」、自己紹介が「からだ」に入っている
   - 案：恋愛・婚活／ADHD・不安症／家族／仕事／からだ
3. **一人称がバラバラ**：最近の記事は「僕」、古い記事は「私」→「私」に統一と決定
4. **不要なページ**：「Sample Page」が公開中、「Hello world!」の下書きが残っている

### 記事の書き方
- **最近の記事（8〜9月）**：文章の温度は十分。ただし
  - 大見出し（H2）が1記事に12〜16個あり、目次が長すぎる
  - 箇条書きや囲み枠がほぼなく、目を休ませる場所がない
  - 「1文ごとに改行」が続き、かえって単調になる
- **古い記事（5〜7月）**：2,000〜3,500字と短め。太字や見出しの工夫が少ない
- 「研究でも〜」と書いているのに出典がない箇所がある → 出典を書くか、表現を弱める

### 人気ブログに近づけるポイント
- 読者が自分と重ねられる「具体的な場面」を1〜2個入れる
- 文末に変化をつける（体言止め、心の声、短い一文）
- 同じ内容を何度も繰り返さない
- 「この記事でわかること」「まとめ」の囲み枠、太字、箇条書きで見た目に変化をつける
- 関連記事へのリンクで、記事どうしをつなぐ

## スクリプトの使い方（wp_post_draft.py）

```
# 新しい下書きを作る（画像は省略可）
python3 wp_post_draft.py 記事.md アイキャッチ画像.png

# 既存の投稿を上書きする（タイトルと本文。画像を付けたときだけアイキャッチも差し替え）
python3 wp_post_draft.py --update 投稿ID 記事.md [アイキャッチ画像.png]
```

- 記事の1行目は「# タイトル」にする
- `**太字**`、段落内の改行、`-` の箇条書き、`##`〜`######` の見出しに対応
- `<` で始まる行（囲み枠・リンクなどのHTML）はそのまま送られる
- 公開・下書きの状態は変えない（公開中の記事を上書きすると、すぐサイトに反映される）
- 上書き後は、WordPressの編集画面で「クラシック」ブロックとして表示される
- サーバーのWAFが DELETE を拒否するので、削除系は `POST …?_method=DELETE` で送る
- 管理画面のログインURLは SiteGuard により `/login_82147`（wp-login.php は使えない）
- 環境変数 WP_URL / WP_USERNAME / WP_APP_PASSWORD が必要。クラウド環境では、ネットワーク設定の許可ドメインに `health-reset-note.com` を入れておく
