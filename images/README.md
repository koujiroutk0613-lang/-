## 写真を差し替えるには
同じファイル名で写真を上書きするだけで、ホームページに反映されます。
お店で撮った実際の写真に替えるのがいちばんおすすめです。
暗めでコントラストの強い写真（ローキー）を選ぶと、高級感が出ます。
